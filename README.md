# 🃏 Memory Card Game

A classic memory matching card game built with pure HTML, CSS, and JavaScript.

## Features
- 3 difficulty levels: 4x4, 6x4, 6x6
- Smooth 3D CSS flip animation
- Move counter and timer
- Best score tracking per difficulty (localStorage)
- Win screen with stats
- Fully responsive and mobile-friendly
- 32 unique emoji icons

## How to Play
1. Click any card to flip it
2. Find the matching pair
3. Match all pairs to win!

## Tech Stack
- HTML5
- CSS3 (3D transforms, transitions)
- Vanilla JavaScript (ES6+)
- No dependencies
